موقع نور الرومانسي - طريقة الاستخدام

1) افتح ملف index.html مباشرة.
2) لتعديل التفاصيل الشخصية افتح ملف script.js وعدّل كائن noorDetails في أول الملف.
3) لتفعيل زر واتساب ضع الرابط بهذا الشكل:
   https://wa.me/201xxxxxxxxx
4) لتشغيل الموسيقى ضع ملف MP3 باسم romantic.mp3 داخل نفس المجلد.
5) الموقع لا يرسل أي بيانات ولا يحتاج قاعدة بيانات أو سيرفر.
6) لرفعه على الإنترنت ارفع المجلد كاملًا على Netlify أو GitHub Pages.
